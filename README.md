## Cloud Security Project – Azure Identity & Zero Trust Defense

### Overview
In this project, I explored core Azure Cloud Security components focusing on identity protection, access control, and Zero Trust principles.  
The goal was to understand how cloud environments are secured and how identity‑based attacks can be detected and mitigated.

### Security Areas Covered

#### Identity Security
- Multi‑Factor Authentication (MFA)  
- Conditional Access policies  
- Identity Protection (risky users, risky sign‑ins)  
- Impossible travel detection  
- Privileged Identity Management (PIM)  
- Role‑Based Access Control (RBAC)

#### Access Security
- Key Vault (secrets, keys, certificates)  
- Managed Identity  
- Service Principals  
- Least Privilege enforcement  

#### Network Security
- Network Security Groups (NSG)  
- Virtual Networks (VNet)  
- Subnets  
- Private Endpoints  
- Firewall basics  

### Hands‑On Tasks Completed
- Created Conditional Access rules  
- Simulated risky sign‑ins  
- Configured MFA enforcement  
- Assigned RBAC roles  
- Created Key Vault secrets  
- Built a secure VNet with NSG rules  
- Reviewed Defender for Cloud recommendations  
- Analysed Sentinel incidents  

### Findings
- Identity is the primary attack surface  
- Conditional Access is the strongest defense  
- Key Vault must use private endpoints  
- NSG rules must follow least privilege  
- Privileged roles should never be permanent  
- Sentinel logs reveal early compromise signs  

### Result
A complete Cloud Security learning project demonstrating practical understanding of Azure identity protection, access control, network security, and Zero Trust architecture.
